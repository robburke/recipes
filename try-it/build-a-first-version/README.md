# Build a first version

Starter prompts for getting a working first version of a small idea. Copy one into your AI assistant and fill in the brackets.

Last updated September 2026.

## Track something with a webcam

From [Galton's Goalie](https://robburke.net/side-quests/galtons-goalie/).

```text
I want to build a small app that uses my laptop's webcam to track [something that moves: balls in a marble run, birds at a feeder]. Talk the approach through with me first and give me two or three options. Then write the first working version in Python with OpenCV as one file, with exact install and run steps. After that, add one feature at a time when I ask.
```

**A good result:** a conversation about the approach first, then one file that runs on your laptop the same day.

A worked example of this kind of app: [GaltonGoalieViz](https://github.com/robburke/GaltonGoalieViz).

## Build a shape in Minecraft

From [Minecraft Build Bot](https://robburke.net/side-quests/minecraft-build-bot/).

```text
I want to build [a shape: a fractal tree, a spiral, a knot] in a Minecraft [Java or Bedrock] world. Write a script that works out the block positions and shows me a quick 3D preview before anything goes into the game. Then turn it into commands I can run in a test world before any shared one. Explain each step so I can do this with [my kid].
```

**A good result:** a preview you can iterate on quickly, and a build that lands in a test world first.
